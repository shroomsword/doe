# Definitions from the Kaitai Struct format gallery

These are copies of definitions from
<https://github.com/kaitai-io/kaitai_struct_formats>, at commit
`f38fd7de89aa6cc171624ba08a0647e06e2ade47`, kept in the same layout (so that
`/common/dos_datetime` finds `common/dos_datetime.ksy`), unchanged. Each says
in `meta.license` how it is licensed: all of these are `CC0-1.0`, a public
domain dedication.

They are here so that the conformance suite checks doe against the reference on
the definitions that people use. The samples are made up (`make_gallery_samples.py`),
and the expected output comes from the reference compiler, as for the other
formats. A definition without samples is only there because another one imports
it.
